---
title: MCP server
description: Connect Claude, Cursor or any Model Context Protocol client to Nurama with scoped tools.
---

The Nurama MCP server exposes the platform as [Model Context Protocol](https://modelcontextprotocol.io) tools. Each running server authenticates with one credential; the credential's memberships and scopes are the only limit on what the model can reach.

## Choose a credential

| | Bot API key (`nrm_bot_…`) | Personal access token (`nrm_pat_…`) |
| --- | --- | --- |
| Messages appear as | The bot | You |
| Audit attribution | The bot user | Your user |
| Best for | Shared or production deployments | Your own machine |
| Who creates it | A workspace admin | You, under **Settings → Tokens** |

Both are passed as `NURAMA_API_KEY`; the server tells them apart by prefix. See [Authentication](/docs/getting-started/authentication) for how to mint each.

## Register the server

The server runs as a stdio subprocess that the client launches. With Claude Code:

```bash
claude mcp add --transport stdio nurama \
  --env NURAMA_API_KEY=nrm_pat_xxx \
  -- npx -y @nurama/mcp
```

Other clients follow the same shape: command, arguments, and `NURAMA_API_KEY` in the launched process's environment. Ask the assistant which Nurama tools it has to confirm the connection.

## What the model can do

Read tools cover memberships, project feeds, chats, messages, boards and tasks. Write tools, such as sending a message or creating a task, are explicitly allow-listed and flagged as mutating in the [tool catalogue](/docs/reference/mcp), which lists every tool with its input schema. The raw catalogue, identical to the server's `tools/list` response, is at [`/mcp-tools.json`](/mcp-tools.json).

Scope the credential to what the deployment needs: a read-only key cannot be talked into writing, whatever the prompt says.

## Which endpoint the server uses

A bot key sends requests to `bot.nurama.com`; a personal access token uses `api.nurama.com`. Rate limits differ accordingly (see [Conventions](/docs/getting-started/conventions)).

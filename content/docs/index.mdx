Nurama is a collaborative asset-review platform: workspaces contain projects, projects contain assets, folders, boards, tasks and chats, and every change fans out to the people watching it in real time. This site documents the four ways you can build on it.

## How the pieces fit

| Layer | Use it when | Reference |
| --- | --- | --- |
| REST API | You need a resource or action and control the HTTP yourself. | [Endpoints](/docs/reference/api) |
| WebSocket | You need to react to changes without polling. | [Events](/docs/reference/websocket) |
| SDK | You write JavaScript or TypeScript. It calls the two layers above with typed methods. | [Method index](/docs/reference/sdk/method-index) |
| MCP | An AI assistant should act on Nurama on a person's or a bot's behalf. | [Tools](/docs/reference/mcp) |

## Machine-readable sources

Everything on this site is generated from documents you can consume directly:

- OpenAPI 3.0: [`/openapi.json`](/openapi.json) or [`/openapi.yaml`](/openapi.yaml)

- MCP tool catalogue: [`/mcp-tools.json`](/mcp-tools.json)
- This site as text for language models: [`/llms.txt`](/llms.txt) (index) and [`/llms-full.txt`](/llms-full.txt) (everything). Every page also has a Markdown variant, reachable from the copy button at the top of the page.

The [build manifest](/manifest.json) records which platform release the documents were generated from.
